# L&G Delícias

Site oficial para consulta do cardápio, montagem do pedido e envio pelo WhatsApp. Inclui área administrativa para marcar produtos disponíveis ou esgotados.

## Recursos
- Cardápio responsivo por categorias
- Carrinho com quantidades e total
- Identificação por nome/apelido e setor
- Pedido formatado para WhatsApp
- Painel administrativo com Cloudflare D1

Nunca salve senhas, tokens ou dados de clientes neste repositório.
